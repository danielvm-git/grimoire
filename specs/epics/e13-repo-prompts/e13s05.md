# e13s05 — Run all checks for one repo

**type:** feature
**risk:** P2
**context:** e13-repo-prompts
**bcps:** 3

## Requirements

The Checks card on the repository detail page carries a **Run checks** button. It
runs every enabled check against that repository only (all matching branches),
skips checks that are already running, and reports the skipped ones. The header
counts not-run checks separately instead of treating them as passing.

## Acceptance Criteria

```gherkin
Feature: Run all checks for one repo
  Scenario: Run checks from the detail page
    Given a tracked repository with enabled checks
    When the user presses Run checks
    Then every enabled check is reserved for that repository
    And checks already running are skipped and reported
    And the page reloads when the run completes

  Scenario: Unknown repository
    When the endpoint is called for an untracked repository
    Then it responds 404

  Scenario: Run already in flight
    When a run for the same repository is already in flight
    Then the endpoint responds 409
```
